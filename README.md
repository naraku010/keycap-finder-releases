# Keycap Finder 데스크톱 앱

[키캡 파인더](https://keycap.keyhub.info) 웹사이트를 Windows 앱으로 쓸 수 있게 만든 설치 파일 저장소입니다.
웹사이트 기능은 그대로 쓰고, 데스크톱 앱에서만 되는 **키캡 합성**이 추가되어 있습니다.

> 소스 코드는 공개하지 않고, 이 저장소에는 설치 파일만 올라갑니다.

## 다운로드

**[최신 버전 받기 →](https://github.com/naraku010/keycap-finder-releases/releases/latest)**

릴리즈 페이지의 **Assets**에서 `Keycap.Finder_버전_x64-setup.exe` 파일 하나만 받으면 됩니다.
같이 있는 `.sig`, `latest.json`은 자동 업데이트용 파일이라 받을 필요가 없습니다.

## 주요 기능

| 메뉴 | 내용 |
| --- | --- |
| 키캡 | GMK, SWG 등 키캡을 색상·이름으로 검색하고 상세 정보와 그룹바이 일정을 확인 |
| 키보드 | 진행 중인 키보드 그룹바이 목록과 상세 정보 |
| 보강판 도면 | 키보드별 보강판 도면 검색 |
| 벤더 | 국내외 키캡·키보드 판매처 모음 |
| **키캡 합성** | 내 키보드 사진에 원하는 키캡을 끼운 모습을 AI 이미지로 생성 (데스크톱 앱 전용) |
| 키또번호 생성기 · 낙타 게임 | 키캡 이름으로 하는 로또 번호 추첨, 타자 게임 |
| 월별 통계 · 환율/직구 | 인기 키캡 순위, 원/달러·원/위안 환율로 직구 타이밍 확인 |

## 설치 방법

1. 위 링크에서 `Keycap.Finder_..._x64-setup.exe`를 받아 실행합니다.
2. **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
   코드 서명 인증서가 없는 개인 배포 앱이라 처음 한 번 나오는 경고입니다.
3. 설치가 끝나면 시작 메뉴의 **Keycap Finder**로 실행합니다.

**지원 환경**: Windows 10 / 11 (64비트).
화면 표시에 Microsoft Edge WebView2를 쓰는데, 최신 Windows에는 기본으로 들어 있고 없으면 설치 중에 자동으로 받습니다.

## 키캡 합성 사용 방법

키캡 합성은 내 PC에 설치된 **OpenAI Codex CLI**의 이미지 생성 기능을 씁니다.
그래서 처음 한 번은 ChatGPT 계정 연결이 필요합니다.

0. Codex CLI는 npm으로 설치되므로 PC에 **Node.js**가 있어야 합니다. 없다면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 먼저 설치하세요.
1. 왼쪽 메뉴 아래쪽의 **설정**을 엽니다.
2. **설치하기**를 눌러 Codex CLI를 설치합니다. 1~2분 걸릴 수 있습니다.
   자동 설치가 안 되면 PowerShell에서 `npm install -g @openai/codex`를 직접 실행한 뒤 **CLI 탐지**를 누르세요.
3. **로그인 창 열기**를 눌러 브라우저에서 ChatGPT 계정으로 로그인한 뒤, 앱으로 돌아와 **로그인 확인**을 누릅니다.
4. **연결하기**를 누르면 준비가 끝납니다.
5. 왼쪽 메뉴의 **키캡 합성**에서
   - 내 키보드 사진을 올리고,
   - 키캡을 이름으로 검색해서 고르거나 키캡 사진을 직접 올린 뒤,
   - **합성하기**를 누르면 1~2분 뒤 결과가 나옵니다. **이미지 저장**으로 내려받을 수 있습니다.

> 이미지 생성은 로그인한 ChatGPT 계정의 사용량으로 처리됩니다. 계정 요금제에 따라 이미지 생성이 안 되거나 사용량 제한이 있을 수 있습니다.
> 올린 사진은 내 PC의 Codex CLI를 거쳐 OpenAI로만 전송되고, 키캡 파인더 서버에는 저장되지 않습니다.

**잘 나오게 하는 팁**
- 키보드 전체가 잘 보이고, 너무 어둡지 않은 사진이 좋습니다.
- 키캡 이미지는 키캡 세트 전체가 보이는 공식 렌더나 키트 사진이 가장 정확합니다.
- 결과가 마음에 들지 않으면 **다시 만들기**를 누르면 새로 생성합니다.

## 업데이트

앱의 **설정 → 앱 업데이트**에서 새 버전을 확인하고, **업데이트 설치**를 누르면 자동으로 받아서 다시 시작합니다.
새 버전 설치 파일을 받아 그대로 덮어 설치해도 됩니다.

## 삭제

Windows **설정 → 앱 → 설치된 앱**에서 **Keycap Finder**를 찾아 제거합니다.
Codex CLI는 따로 설치된 프로그램이라, 필요 없으면 `npm uninstall -g @openai/codex`로 지웁니다.
